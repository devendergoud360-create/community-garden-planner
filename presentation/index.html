The Problem

Why a focused local garden tool is needed

Manual tracking breaks down

Spreadsheets and paper logs lead to calculation errors, misplaced entries and delayed status insights.

Fragmented tools

Bed inventory, sowing dates and harvest notes live in different places — no single source of truth.

Enterprise-grade friction

Existing solutions demand steep learning curves, paid licenses or intrusive network setups.

No quick status view

Hard to spot overdue beds, upcoming harvests or failing crops at a glance.

Goal: a focused, accessible Python application that validates entries, persists records locally and presents actionable summaries.

The Solution

One app, two interfaces, shared data

Interactive CLI

12-option menu, guided prompts, paginated tables and ANSI status flags.

Flask Web UI

Dashboard, records table, forms, charts and report downloads in the browser.

Shared core logic

Both interfaces use the same models, validation, analytics and storage modules.

Defensive validation

Regex, type and range checks re-prompt on bad input — no crashes.

Local persistence

Atomic JSON writes; CSV import/export; corrupt files recovered automatically.

Actionable analytics

Summaries, threshold warnings, charts and multi-format exports.

44-row demo dataset included — normal entries, boundary values and edge cases.
